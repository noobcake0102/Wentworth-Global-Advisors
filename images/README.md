## Notes

- **Format:** JPEG preferred. WebP also works.
- **File size:** Compress to under 500 KB per image for performance. Use Squoosh or TinyJPG.
- **Color:** All images render dark and desaturated via CSS (luminosity blend + low opacity for hero/page images). Don't over-process before uploading.
- **The slots are live** — once you drop the file in and push, the image appears automatically. No code changes required.
